1. First-Time Setup

  1. Always open Nexus via Launch Nexus.vbs in the C:\NEXUS folder — never double-click the HTML file directly. This starts a small local server, which Real-Debrid requires to work at all.
  2. Go to Settings and paste in your API keys: TMDB (free, needed for posters/search), Real-Debrid (needed for playback), Groq (free, powers the AI Assistant), OpenSubtitles (free, optional — enables real subtitles).
  3. The first time you press play, Chrome will show a one-time "Open Windows PowerShell?" popup — tick Always allow and click Open. This is the real, legitimate handoff to mpv (the video player) — not a bug.

2. Browsing & Searching

  1. Use the search bar at the top to find anything — it searches your local library instantly, then live TMDB results as you keep typing.
  2. Movies, TV Shows, Anime, and Bollywood each have their own section — Movies/TV/Live TV sit in the top bar, the rest under "More" — pulling real, current titles from TMDB.
  3. Bollywood and Anime have category tabs (Action, 2024 Releases, Tamil, Telugu, etc.) that filter to real, distinct results — not decorative.

3. Playing Movies & TV Shows

  1. Click any movie poster to open the stream picker — it searches real sources and shows quality-filtered results (4K/1080p/720p/etc, colour-coded).
  2. For TV shows, clicking the poster opens Seasons first, then Episodes, then the same stream picker.
  3. If subtitles are found for that title, a language dropdown appears above the stream list — pick one before clicking play.
  4. Playback opens in a small corner window (top-right) that stays on top of other apps, so you can keep browsing or working while watching.

4. Favourites & Live Sports

  1. In Sports or Live TV, click the star icon on any channel to favourite it — favourited channels always sort to the top.
  2. Use the search box within those sections to find a specific channel by name.
  3. Note: some well-known channels (e.g. Sky Sport NZ, club-specific channels) aren't on the free legal channel list this app uses — only genuinely free-to-air/legal streams are included.

5. Troubleshooting

  1. "Something went wrong resolving this stream" — Real-Debrid calls are routed through Lounge's cloud content relay (whetudigital.co.nz) because Real-Debrid's API sends no CORS headers. This works with the PC off; check your internet connection, or that your Real-Debrid key in Settings is correct.
  2. Settings look empty / keys missing — each origin (file:// vs localhost:8899) has separate storage. If you ever see empty keys, re-paste them once on that origin; they'll stick from then on.
  3. Nothing happens on play — check you approved the one-time "Open Windows PowerShell?" popup with "Always allow" ticked.

VPN Setup Guide

Device-by-device instructions for putting Lounge's traffic behind a VPN — including which platforms can do it per-app and which can't. Informational only; nothing is installed or changed for you.

Weather Location

City for the live weather widget — powered by Open-Meteo (free, no API key needed)

Movie Poster API (TMDB)

Free key from themoviedb.org/settings/api (2-min signup, no card) — enables real posters instead of icons. Poster data provided by TMDB.

Real-Debrid API Key

From real-debrid.com/apitoken (requires an active premium subscription) — resolves scraped torrents into direct playable links.

Playback Sources

What Lounge can currently resolve a film or episode with. Live TV and Live Sports are separate and need none of these.

Plex (free account)

Plex's ad-supported Movies & Shows catalogue is free and does not need Plex Pass, but it does need a Plex account — there is no anonymous access. Signing in links this device with a 4-character code; Lounge stores the returned token on this device only.

Groq API Key (AI Assistant)

From console.groq.com (free tier) — powers the AI Assistant chat.

OpenSubtitles API Key

From opensubtitles.com/en/consumers (free — sign up, create an API consumer) — enables real subtitle search/download for playback.

Watch History

Clears your local "Continue Watching" list. This only lives in this browser/device — there's no account or cloud sync.

Where your traffic leaves from

A web page cannot see whether a VPN app is running on your device — no browser gives it that power. What it can see is the public address the internet answers you on, and who owns it. When a VPN is carrying your traffic, that owner is the VPN company instead of your home provider. So: save your normal connection once, and this panel will tell you when the current one looks different. It is an indirect signal, not a verdict.
